# Fridge Management System

A final-year academic project developed for a beverage manufacturing company to replace
manual, paper-based processes with a centralized web-based system.

## Project Overview
The system manages the allocation and servicing of fridges provided to customers such as
spaza shops and shebeens. It improves operational efficiency, inventory tracking, and customer
service through automation.

## Core Functionalities
- Customer and fridge management
- Inventory control and stock tracking
- Fault reporting and technician scheduling
- Fridge maintenance and service history
- Supplier and fridge procurement management

## Technologies Used
- C#
- MySQL
- RESTful APIs
- GitHub

## Project Type
Third-Year Final Project (ONT3010)
